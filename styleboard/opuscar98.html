How it was made

No video model drew this film. Claude Opus 5.5, working in Claude Code, wrote each set, the character animation, the camera moves, the edit and the score as code, and the code rendered them to video.

这部片没有用视频模型生成。Claude Opus 5.5 在 Claude Code 里把每个布景、角色动画、运镜、剪辑和配乐都写成代码，再由代码渲染成视频。

The same approach is packaged as Lemo-Opuscar: {{N_ALL}} film styles, each a style prompt plus a demo film, installable as a Claude Code skill so your agent can direct a film about your own topic.

同样的做法整理成了 Lemo-Opuscar：{{N_ALL}} 种影片风格，每种是一份风格提示词加一支样片，可以装成 Claude Code skill，让你的 agent 给你自己的题材导一支片。
