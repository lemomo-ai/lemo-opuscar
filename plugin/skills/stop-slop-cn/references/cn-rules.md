# 中文口播表达补充

规则思想参考 https://github.com/w568w/stop-slop-cn ，版本 cb43e63cd5f471549ddd3aa2f670b04ca4781ce8；以下为本地重新整理，未复制原例句。

- 开场尽快交代具体事情；删掉没有信息的赞同、恭维和自我表态。
- 结尾承担正文任务，不额外推销下一轮服务，也不许下无从核对的承诺。
- 将行业暗语还原成谁做了什么；动词需要宾语，评价需要对象。
- 口语省略应以听懂为准，避免把多个孤立单字拼成工作汇报。
- 对比必须服务主题。实际存在的事实差异和否定应保留，不为躲避句式而删掉。
- 按中文搭配组织句子，避免照搬外语词序和隐喻。
- 连续出现相同引导句时，检查是否只是重复铺垫；不要机械换同义词。
- 口播用连贯句子表达因果；清单只用于确实并列的信息。
- 去掉与当前事实无关的防御性声明；涉及事实边界、来源限定和风险说明时仍应保留。

这是一份审稿提示，不是自动禁词替换表，也不能据此推断作者身份。
