# Kokoro v1.0 model files

The `voice` release pack redistributes `kokoro-v1.0.onnx` and `voices-v1.0.bin` from the
[kokoro-onnx model-files-v1.0 release](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0).
The underlying [Kokoro-82M model and voices](https://huggingface.co/hexgrad/Kokoro-82M) are published by
hexgrad under Apache 2.0. The ONNX release credits Taylor Chu for the optimised float32 export.
The pack includes the [Apache 2.0 text](LICENSE-Apache-2.0.txt).

The separately installed kokoro-onnx runtime is MIT-licensed. The model and voice files are third-party
assets under Apache 2.0; no Lemo-Opuscar licence, including a commercial licence, covers them.
